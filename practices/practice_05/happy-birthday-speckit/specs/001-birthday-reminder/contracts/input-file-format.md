# Contract: формат входного файла

Кодировка: UTF-8 (с BOM или без) или Windows-1251. Разделитель строк: `\n` или `\r\n`.

## Грамматика строки

```text
line     = ws* fullName ws* "(" date ")" ws* "|"? ws*
fullName = word (ws+ word)*          ; 1+ слов, буквы (кириллица/латиница), дефис, апостроф
date     = DD "." MM "." YYYY        ; ровно 2.2.4 цифры
```

## Правила

| Вход | Результат |
|---|---|
| `Романова Марина Викторовна (19.05.1972)\|` | Person: Романова / Марина / Викторовна, 1972-05-19 |
| `  Романова   Марина Викторовна (19.05.1972)  ` | то же (пробелы схлопнуты, `\|` необязателен) |
| `Иванов Иван (01.01.1990)\|` | Person без отчества |
| пустая строка / только пробелы | игнорируется, не считается ошибкой |
| `Иванов (31.02.1990)\|` | skipped, reason `invalid-date` |
| дата позже «сегодня» | skipped, reason `future-date` |
| `Иванов Иван 01.01.1990` / любой другой мусор | skipped, reason `format` |
| повтор той же ФИО+даты (с точностью до регистра, `ё/е`, пробелов) | объединяется, `duplicatesMerged += 1` |

Номер строки в `SkippedLine.lineNumber` — 1-based, как в текстовом редакторе.

## Сообщения пользователю (presentation)

- `format` → «Не удалось распознать строку»
- `invalid-date` → «Такой даты не существует»
- `future-date` → «Дата рождения в будущем»
