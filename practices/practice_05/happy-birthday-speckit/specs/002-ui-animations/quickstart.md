# Quickstart: проверка анимаций

**Предусловия**: `npm install`, `npm start`, открыть http://localhost:4200, загрузить файл со
списком людей. Контракт движения: [contracts/motion.md](contracts/motion.md).

Для оценки на глаз: DevTools → Animations, скорость 10–25%.

1. **M1**: нажать и удерживать любую кнопку: она слегка «вдавливается». Отпустить: возвращается.
2. **M2**: без друзей нажать на человека в карусели. Подтверждение появляется сверху, через ~4 с
   само уходит тем же путём. Быстро добавить ещё двоих: текст обновляется без рывков.
3. **M3**: на «Мои друзья» удалить среднюю строку. Она затухает и схлопывается, нижние строки
   плавно поднимаются.
4. **M4**: загрузить файл ещё раз: итог импорта появляется плавно.
5. **M5/M6/M7**: пройти по всем пунктам меню. Содержимое появляется мгновенно-мягко, по ссылкам
   можно кликать сразу. На главной блоки идут каскадом, на статистике столбцы растут слева.
6. **M8**: добавить в друзья человека с сегодняшним днём рождения, открыть главную: конфетти
   один раз (≤ 2 с). Уйти и вернуться: конфетти нет. Перезагрузить: снова есть.
7. **Reduced motion**: DevTools → Rendering → Emulate `prefers-reduced-motion: reduce`.
   Повторить шаги 1–6: ничего не движется, удалённая строка исчезает сразу (проверка риска R9),
   карусель статична, конфетти нет.
8. **FR-010**: прокрутить и поискать в «Все люди»: строки не анимируются, плавность как раньше.
9. **Gates**: `npm run build` и `npm test` проходят. Покрытие чистых функций не меньше, чем до
   фичи (новых чистых функций нет).
