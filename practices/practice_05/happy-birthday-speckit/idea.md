# Идея: «Happy Birthday» — напоминалка о днях рождения

## Что есть сейчас

У меня есть текстовый файл со списком людей: ФИО и дата рождения. Записи выглядят так:

```
Романова Марина Викторовна (19.05.1972)|
Романова Марина Николаевна (19.08.1972)|
Романова Марина Сергеевна (20.02.1986)|
Романова Марина Юрьевна (03.03.1983)|
```

Каждая запись на отдельной строке: ФИО, в скобках дата рождения в формате ДД.ММ.ГГГГ, в конце строки стоит `|`.

## Что я хочу

Приложение на Angular, которое берёт этот файл и помогает не забывать о днях рождения.

### Главное
- **У кого день рождения сегодня.** Как только я открываю приложение, сразу вижу, кого нужно поздравить сегодня.
- **Ближайшие дни рождения.** Список тех, у кого день рождения скоро, по порядку от ближайшего. Возле каждого человека написано, через сколько дней праздник и сколько ему исполнится.
- **Весь список.** Можно посмотреть всех людей из файла.
- **Поиск.** Можно найти человека по фамилии, имени или отчеству.

### Как это должно ощущаться
- Простое и понятное приложение, разобраться без инструкции.
- Всё на русском языке.
- Даты показываются в привычном виде (например, «19 мая»).
- Если в списке много людей с одинаковой фамилией и именем, их легко различить по отчеству и дате.

## Чего пока не нужно
- Регистрации и входа.
- Редактирования списка внутри приложения: данные берутся из текстового файла.
- Рассылки поздравлений и уведомлений.
