Комментарий о шуме и воспроизводимости:
- Наблюдается значительный разброс между повторами (например, A: 38–131 s), вероятно из-за:
  - прогрева модели и кэша при первом обращении;
  - фоновой нагрузки CPU/IO;
  - вариативности длины ответа и скорости токен-декодинга на CPU.
- Для повышения воспроизводимости:
  - выполнять прогоны после прогрева, с одинаковыми параметрами и вопросом;
  - минимизировать фоновые процессы;
  - фиксировать длину ответа меньшим num_predict;
  - при необходимости — использовать более лёгкую модель на CPU для снижения разброса.
