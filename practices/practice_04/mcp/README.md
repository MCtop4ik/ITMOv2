# MCP server: simple-server

Этот сервер реализует два инструмента:

- add(a: int, b: int) -> int — складывает два числа.
- validate_json(file_path: str) -> object — проверяет валидность JSON-файла и возвращает сводку.

## Быстрый запуск

Требуется Python 3.11+ и пакет `mcp`. В этом репозитории сервер запускается через OpenCode, конфигурация находится в корневом `opencode.json` (раздел `mcp.simple-adder`).

Локально можно запустить вручную:

```
python main.py
```

## Примеры

Пример валидного файла: `examples/valid.json`.

Пример невалидного файла: `examples/invalid.json` — отсутствует закрывающая скобка у массива; это демонстрирует ошибочный ввод.

Ожидаемые результаты вызова `validate_json`:

- Для валидного файла: `ok: true`, `type: dict`, `top_level_keys` включает `name`.
- Для невалидного файла: `ok: false`, `error` содержит `JSONDecodeError` с указанием строки и столбца.
