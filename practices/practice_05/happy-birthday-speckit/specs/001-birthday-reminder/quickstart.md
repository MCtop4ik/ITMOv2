# Quickstart: проверка фичи

## Требования

- Node.js 24+, npm 11+ (Angular CLI 22 ставится как dev-зависимость проекта)
- Современный браузер (Chrome, Firefox, Safari последних версий)

## Запуск

```bash
npm install
npm start          # ng serve → http://localhost:4200
npm test           # ng test: юнит-тесты + отчёт покрытия в coverage/
npm run build      # продакшн-сборка
```

Тестовые данные: `scripts/generate-people.mjs` создаёт файл на 100 000 строк
(`node scripts/generate-people.mjs > people-100k.txt`), в том числе людей с днём рождения сегодня,
завтра, 3 дня назад, 29 февраля и несколько некорректных строк.

## Сценарии проверки

| # | Действие | Ожидаемый результат | Спецификация |

| 6 | Добавить в друзья людей с ДР сегодня, завтра, 3 дня назад | Видны в «Сегодня», «Ближайшие» («завтра»), «Недавно были» («3 дня назад») | FR-010…013 |
