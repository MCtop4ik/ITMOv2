# Data Model: Анимации интерфейса

Доменных сущностей фича не добавляет: слой `domain` не меняется. Появляется только
состояние слоя presentation:

| Состояние | Где | Тип | Правила |
|-----------|-----|-----|---------|
| `justAdded` | `HomePage` (уже есть) | `signal<string \| null>` | После установки имени сбрасывается в `null` через 4 с. Повторная установка перезапускает таймер. Кнопка «Скрыть» сбрасывает сразу. Таймер очищается при уничтожении компонента. |
| `celebrated` | переменная модуля `home.page.ts` | `boolean` | Принимает `false` при загрузке приложения. Становится `true` при первом показе конфетти. Конфетти показываются, только если `!celebrated && facade.today().length > 0`. |
