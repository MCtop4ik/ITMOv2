# Contract: экраны и маршруты

Навигация — вкладки в шапке; кнопка «Загрузить файл» доступна на всех экранах, также работает
перетаскивание файла в окно.

| Маршрут | Экран | Покрывает |
|---|---|---|
| `/` | Главная: «Сегодня», «Ближайшие» (7/30/90), «Недавно были» — только друзья; без друзей — призыв + карусель; без файла — экран загрузки | US1, US2, US4, FR-010…014, FR-024, FR-025 |
| `/friends` | Мои друзья: по алфавиту, дата, дни до ДР, «Убрать» | US1a, FR-029, FR-030 |
| `/people` | Все люди: поиск, сортировка (алфавит / ближайший ДР), звёздочка «В друзья», virtual scroll | US3, FR-015…018 |
| `/people/:id` | Карточка: дата, возраст, дни до ДР, день недели, знак зодиака, «Скопировать поздравление», «В друзья / Убрать» | US5, FR-019, FR-020 |
| `/calendar` | 12 месяцев со счётчиками, текущий выделен; `/calendar/:month` — именинники месяца | US6, FR-021 |
| `/stats` | Статистика по файлу | US7, FR-027, FR-028 |
| `**` | редирект на `/` | |

`:id` — `encodeURIComponent(PersonId)`. Если человек с таким id отсутствует в текущем файле, но
есть в друзьях — карточка строится по данным друга; иначе сообщение «Человек не найден».

Пустые состояния: нет файла → экран загрузки на всех вкладках, кроме `/friends`; ничего не найдено
→ «Никого не найдено»; после импорта — сводка «Загружено N, пропущено M (показать), дубликатов K».
