# Эксперимент: влияние temperature и seed

Цель: сравнить ответы и скорость модели при temperature=0.8 (hot) и 0.2 (cool) для одинаковых seed 42, 43, 44. Для скорости учитываем медиану трёх прогретых повторов на конфигурацию. Холодный старт фиксируем отдельно. TTFT не измеряем (ответ не потоковый).

## Метод
- Скрипт `experiment.py` (mode=system) отправляет запрос в локальный Ollama (qwen3.5:2b). Поля метрик берём из JSON: `wall_seconds`, `load_seconds`, `total_seconds`, `decode_tokens_per_second`.
- Для каждого сочетания температуры и seed:
  1) один холодный прогон с суффиксом `_cold.json`;
  2) три прогретых прогона с суффиксами `_rep{1..3}.json`;
  3) медиану считаем по `decode_tokens_per_second` у прогретых повторов.
- Результаты не перезаписываются: уникальные имена файлов.

## Сырые файлы результатов
- Директория: `results/`.
- Горячие (0.8): `hot42_*`, `hot43_*`, `hot44_*`.
- Холодные (0.2): `cool42_*`, `cool43_*`, `cool44_*`.

## Итоги по скорости (медиана decode_tokens_per_second)

Temperature 0.8
- seed 42: rep1=19.10, rep2=18.52, rep3=17.54 -> медиана 18.52 ток/с
- seed 43: rep1=17.63, rep2=17.45, rep3=16.93 -> медиана 17.45 ток/с
- seed 44: rep1=16.15, rep2=14.58, rep3=15.50 -> медиана 15.50 ток/с

Temperature 0.2
- seed 42: rep1=14.22, rep2=13.84, rep3=14.25 -> медиана 14.22 ток/с
- seed 43: rep1=15.58, rep2=14.79, rep3=15.21 -> медиана 15.21 ток/с
- seed 44: rep1=15.69, rep2=15.82, rep3=14.24 -> медиана 15.69 ток/с

Наблюдение: на этой задаче 0.8 чаще быстрее по decode_tokens_per_second для seed 42 и 43, но для seed 44 скорости сопоставимы, а иногда 0.2 не хуже. Разброс скоростей по seed заметен.

## Холодный старт
- 0.8: hot42_cold total≈0.652с, hot43_cold total≈0.608с, hot44_cold total≈5.449с (для seed 44 вышло длиннее: больше eval_count=88)
- 0.2: cool42_cold total≈0.750с, cool43_cold total≈0.760с, cool44_cold total≈0.756с

Вывод: по холодному старту значимых отличий между 0.2 и 0.8 нет, отличие обусловлено длиной ответа (eval_count). Аномалия seed 44 у 0.8: модель выдала ~88 токенов, что увеличило суммарную длительность.

## Анализ фактов и ошибок (6 ответов)
- hot 0.8 seed 42: «В предоставленных материалах нет ответа.» Короткий ответ, соответствует системе. Фактически верно: CI не указан в контексте. Ошибок нет.
- hot 0.8 seed 43: такой же краткий ответ. Фактически верно. Ошибок нет.
- hot 0.8 seed 44: ответ содержит краткий вывод и расширенное пояснение с перечислением того, что есть в контексте и чего нет. Это допустимо, не выходит за рамки; фактически верно. Ошибок нет.
- cool 0.2 seed 42: краткий ответ «нет ответа». Фактически верно. Ошибок нет.
- cool 0.2 seed 43: краткий ответ «нет ответа». Фактически верно. Ошибок нет.
- cool 0.2 seed 44: краткий ответ «нет ответа». Фактически верно. Ошибок нет.

Замечания: высокая temperature не обязана давать ошибку — в наших данных ошибок нет. Низкая temperature не гарантирует правильность — в этой задаче обе температуры дали правильные (по инструкции) ответы.
